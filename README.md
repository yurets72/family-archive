# 📜 Семейный архив рода Девятковых

## О проекте

Это долгосрочный исследовательский проект по восстановлению истории семьи Девятковых и Герасимовых.

Проект объединяет:

- генеалогическое древо;
- архивные документы;
- фотографии;
- биографии;
- военные сведения;
- сведения о репрессиях;
- семейные воспоминания;
- интерактивный офлайн-сайт.

Главная цель проекта — сохранить историю семьи для будущих поколений.
