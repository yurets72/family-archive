# Проект: Архив рода Девятковых

Версия документа: 1.0

---

# Цель проекта

Создать единый автономный (offline) семейный архив рода Девятковых и Герасимовых в виде одного HTML-файла, который можно открыть на любом современном устройстве без установки дополнительных программ.

Проект должен сохранить семейную историю, архивные сведения и результаты генеалогических исследований для будущих поколений.

---

# Образ результата

После открытия файла пользователь должен иметь возможность:

• просмотреть генеалогическое древо;

• найти любого родственника;

• открыть карточку человека;

• увидеть уровень достоверности информации;

• ознакомиться с архивными источниками;

• понять историю семьи даже без пояснений автора.

Проект должен одинаково хорошо работать как на компьютере, так и на телефоне.

---

# Основные принципы

1. Не выдумывать факты.

Если информация неизвестна —
она помечается как неизвестная.

Если информация является гипотезой —
она так и обозначается.

---

2. Один источник истины.

Все сведения сначала попадают в единую базу данных проекта.

Интерфейс лишь отображает эти данные.

---

3. Архитектура стабильна.

Добавление новых родственников,
документов или фотографий
не требует изменения структуры проекта.

Меняются только данные.

---

4. MVP важнее идеальности.

Любая версия должна быть полностью рабочей.

Красота и дополнительные функции появляются только после завершения MVP.

---

5. Каждая версия завершена.

Запрещается оставлять "полуготовые" функции.

Если раздел существует —
он должен работать.

---

6. Новые идеи не тормозят разработку.

Любая идея сначала попадает в список TODO.

Она реализуется только после завершения текущего этапа.

# Основная идея проекта

Проект создается не только для современников.

Он должен быть понятен детям, внукам и правнукам семьи спустя десятилетия.

Поэтому приоритет всегда имеют:

понятность,
простота,
достоверность,
долговечность.
